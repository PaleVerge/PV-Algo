# 已知三点求平行四边形第四个点

## 一、问题描述
给定平面（或多维空间）中三个不共线的点 $A(x_1, y_1)$、$B(x_2, y_2)$、$C(x_3, y_3)$，求解所有互不相同的第四个点 $D(x, y)$，使得以 $A, B, C, D$ 为顶点的四边形构成一个平行四边形。

---

## 二、数学原理与推导

### 1. 核心几何性质
平行四边形的核心性质为：**对角线互相平分**（即两条对角线的中点重合）。

设对角线端点分别为 $(P_1, P_2)$ 与 $(P_3, P_4)$，其中点坐标满足：
$$\frac{P_1 + P_2}{2} = \frac{P_3 + P_4}{2} \iff P_1 + P_2 = P_3 + P_4$$

因此，第四个顶点的向量关系式为：
$$P_4 = P_1 + P_2 - P_3$$

### 2. 向量平移视角
也可以从对边平行且相等的向量关系推导：
- 若以 $AB$ 和 $CD$ 为对边，且 $\vec{AB} = \vec{DC}$，则：
  $$B - A = C - D \implies D = A + C - B$$

---

## 三、3 种组合方案及公式

已知三点 $A, B, C$，任选两点作为其中一条对角线，剩下的一个点与待求点 $D$ 构成另一条对角线。根据对角线的选择，恰好存在 **3 种互不重复的解**：

### 方案 1：以 $AB$ 为对角线
- 对角线为 $AB$ 和 $CD_1$
- 关系式：$A + B = C + D_1$
- 坐标计算：
  $$D_1 = A + B - C = (x_1 + x_2 - x_3,\; y_1 + y_2 - y_3)$$

### 方案 2：以 $AC$ 为对角线
- 对角线为 $AC$ 和 $BD_2$
- 关系式：$A + C = B + D_2$
- 坐标计算：
  $$D_2 = A + C - B = (x_1 + x_3 - x_2,\; y_1 + y_3 - y_2)$$

### 方案 3：以 $BC$ 为对角线
- 对角线为 $BC$ 和 $AD_3$
- 关系式：$B + C = A + D_3$
- 坐标计算：
  $$D_3 = B + C - A = (x_2 + x_3 - x_1,\; y_2 + y_3 - y_1)$$

> **结论**：只要 $A, B, C$ 三点互不相同且不共线，$D_1, D_2, D_3$ 这三个点**彼此互不相同**，且均与 $A, B, C$ 互不相同。

---

## 四、特殊情况判断（共线检测）

在计算前需确保三点不共线。在二维平面中，可通过**向量叉积**判断是否共线：
$$\vec{AB} \times \vec{AC} = (x_2 - x_1)(y_3 - y_1) - (y_2 - y_1)(x_3 - x_1)$$

- 若叉积为 $0$：三点共线，退化为同一直线上的点，无法构成非退化的平行四边形。
- 若叉积不为 $0$：三点可构成非退化三角形，确定存在上述 3 个唯一解。

---

## 五、C++ 代码实现

```cpp
#include <iostream>
#include <vector>

struct Point{
    long long x,y;
};

// 判断三点是否共线（叉积为0）
bool is_collinear(const Point& a,const Point& b,const Point& c){
    return (b.x-a.x)*(c.y-a.y)-(b.y-a.y)*(c.x-a.x)==0;
}

// 求第四个点的3种可能解
std::vector<Point> get_fourth_points(const Point& a,const Point& b,const Point& c){
    if(is_collinear(a,b,c)){
        return {};// 三点共线无有效平行四边形
    }
    std::vector<Point> res;
    // D1: AB为对角线
    res.push_back({a.x+b.x-c.x,a.y+b.y-c.y});
    // D2: AC为对角线
    res.push_back({a.x+c.x-b.x,a.y+c.y-b.y});
    // D3: BC为对角线
    res.push_back({b.x+c.x-a.x,b.y+c.y-a.y});
    return res;
}

int main(){
    Point a={0,0},b={4,0},c={1,3};
    auto pts=get_fourth_points(a,b,c);
    for(size_t i=0;i<pts.size();++i){
        std::cout<<"D"<<i+1<<": ("<<pts[i].x<<", "<<pts[i].y<<")\n";
    }
    return 0;
}
```

## 六、多维空间推广
对于更高维空间（如三维点 $(x, y, z)$）：
公式完全相同，分别对每个坐标分量独立计算即可：
$$D_k = P_i + P_j - P_m$$
其中共线检测可使用向量叉乘模长是否为零（或判断向量是否线性相关）。
