### 快速幂
![快速幂.png](assets/快速幂.png)
$$ a^b $$
$ 若b为偶数: $
$$ a^b=a^{b/2}*a^{b/2}=(a^{b/2})^2=(a^2)^{b/2} $$

$ 若b为奇数,则b-1为偶数,由上可知:: $
$$ a^b=a*a^{b-1}=a*(a^{(b-1)/2})^2=a*(a^2)^{(b-1)/2}$$
#### 代码实现:
```c++
void qmi(int a,int b){
    while (b){
        int ans=0;
        if (b&1){
            ans=ans*a;
        }
        b>>=1;
        a=a*a;
    }
    return ans;
}
```

### 费马小定理
> 若p为质数，且gcd(a,p) = 1，则 $a^{p-1} = 1 (mod\ p) $
>
> 因为p为质数，所以任意小于p的正整数a，都有gcd(a,p)=1，即a和p互质
>
> 一般题目给的模数都是一个质数，因此满足费马小定理，可以用来求逆元
---
### 逆元
> 若 $$ a*b=1 (mod\ p) $$ 则称b为a的逆元，也记作$$a^(-1)或1/a$$
>
> 注意逆元是一个整数.
>
> $$a^{p-1} = 1 (mod\ p)$$  $$a^{p-2} = 1/a$$ a的逆元: $$b =a^{p-2}$$
#### 代码实现:
```c++
ll inv(ll n){
    return qmi(n,p-2);
}
```
