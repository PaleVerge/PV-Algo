# 差分

---

```c++
diff[i] = a[i]-a[i-1];
```

对差分数组做前缀和可以还原为数组:
```c++
diff[1] = a[1];
diff[2] = a[2]-a[1];
//...
diff[n] = a[n]-a[n-1];

prefix[n] = E(i,j=1)a[j]
```
利用差分数组可以实现快速的区间修改，将区间[l,r]都加上x：
```c++
diff[l] += x;
diff[r+1] -= x;
```
再做前缀和恢复原数组即可。

差分数组不能实现边修改边查询，只能实现多次修改后多次查询。

差分的实现：
```c++
a[0]=0;
for(int i=1;i<=n;i++){
    diff[i] = a[i]-a[i-1];
}
diff[l] += x;
diff[r+1] -= x;
```
